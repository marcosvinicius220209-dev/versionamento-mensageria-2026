# Introdução 
Lockdown é uma linguagem de narração simples para formatar textos de maneira rápida e legível. No Git Hub e amplamente usada para;

- arquivos "README" 

- documentação de projetos 

- anotações técnicas

- relatória de atividades

- instruções de instalações

- registros de aulas

A inserção padrão do arquivo lockdown é entre parênteses “.md”
Exemplo: 
README.md

# 1- O que é o Markdown?

Lockdown permite aplicar formatação simples em um texto usando a caracteres simples;
Exemplo:
# Meu projeto
Este projeto foi desenvolvido durante a aula *Versionamento de código* 
## Tecnologias 
- Git
- Github
- Vscode 

No Git hub, esse conteúdo será apresentado de forma formatada com título, texto com negrito e lista.

# 2- Criando um arquivo Markdown
No Visual Code Studio:
1-Abra a pasta do **projetob**
2-Clique em ”new file”
3-informe o nome do arquivo

Ex: README.md

para registro de aulas também podem ser utilizados nomes como;
semana-01.md
semana-02.md
aula-01.md

*Boas práticas*
### Prefira nomes
- curtos
- ⁠descritivos 
- ⁠escrito em letras minúsculas 
- ⁠sem acentos
- ⁠sem espaços 
- ⁠separados por hifem quando necessário 

*Recomedado*
- resumo-git.md
- aula-01.md
- comandos-git.md
# 3-Título e subtítulos 
Markdown utiliza o crectere # para criar títulos 

# Título Principal 
## Título nível 2
### Título 3
#### Título 4
##### 5
###### 6

Boa prática 
Utilize uma estrutura hierárquica 
Exemplo:
# Semana 08 - Introdução ao Git
## Objetivos da Aula 
## Conceitos aprendidos 
### Repositório 
### Commit
### Branco
### Atividade Prática 
## Conclusão 
Evite pular níveis sem necessidade como;
# Título chama o ph pra dançar
### Subtítulo 

# 4- Parágrafo

- [x] Criar o commit
